# Landing Page di FAVELLA 1

Questa directory contiene il codice sorgente (React + Vite + TailwindCSS) per il sito web ufficiale/landing page commerciale del motore narrativo FAVELLA 1.

## Come Avviare
1. Installare le dipendenze: `npm install`
2. Avviare il server di sviluppo: `npm run dev`
3. Per la build: `npm run build`
