# v0.1.0.1 - Miglioramenti UX IDE

**Data:** 28 Novembre 2025
**Stato Progetto:** Alpha
**Versione IDE:** v0.1.0.1

## 🛠️ Modifiche all'IDE (Favella Studio)

Questo aggiornamento minore si concentra sul miglioramento dell'esperienza utente (UX), introducendo una protezione contro la perdita accidentale di dati.

### Funzionalità Aggiunte:
1.  **Rilevamento Modifiche Non Salvate:**
    *   L'IDE ora tiene traccia delle modifiche apportate al codice nell'editor.
    *   Quando il file viene modificato, un asterisco (`*`) appare accanto al titolo della finestra (es. `Favella Studio v0.1 - storia.fav *`).

2.  **Protezione alla Chiusura:**
    *   Tentando di chiudere l'applicazione con modifiche non salvate, viene mostrata una finestra di dialogo di conferma.
    *   Opzioni disponibili: **Salva** (salva ed esce), **Scarta** (esce senza salvare), **Annulla** (rimane nell'IDE).

3.  **Feedback Visivo:**
    *   Il titolo della finestra si aggiorna dinamicamente per riflettere lo stato del file (salvato/modificato) e il nome del file corrente.
